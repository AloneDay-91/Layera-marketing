# Layera marketing

Public landing for [Layera](https://github.com/AloneDay-91/Layera). This repo is the website only. The file manager lives in the Layera repository.

```bash
pnpm install
pnpm dev
```

The site runs at `http://localhost:3002`.

On Dokploy, deploy this repository with `docker-compose.yml` and attach a domain to `web` (container port `3000`).
